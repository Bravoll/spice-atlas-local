# 原位升级香料图鉴

本轮从已公开推送 `b2a3fffec7ca1a9c29bef7ec38cd77165f32f108` 的 v0.7 升到 v0.8。完整包另携带真实 0.6→0.7→0.8 链；小补丁支持 v0.7 与此前的 v0.8 候选版。**程序发行版本**与应用里的**馆藏工作版本**不同：升级程序不会新建、删除或切换馆藏，也不会把新版空数据库覆盖到原来的数据。

## Windows 使用步骤

1. 在旧图鉴托盘中选择“停止服务并退出”。只关闭网页或隐藏启动窗口还不够；升级器检测到原客户端仍运行时会停止。
2. 将增量补丁解压到一个临时目录。也可以下载完整 v0.8，新包同样包含升级器。
3. 双击**新包中的** `Update_Atlas.cmd`，选择原来的香料图鉴目录，也就是包含 `main.py`、`pyproject.toml` 和原 `.venv` 的文件夹。也可把旧目录拖到 CMD 文件上。
4. 校验通过后，升级器只更新清单中列出的程序文件。成功后从原目录重新启动图鉴；目录名仍可叫 `Spice_Atlas_Local_v0.6`，程序内版本已经是 v0.8，路径不改名。
5. 保留 `data/updates/` 中的备份和事件日志，确认本机验收通过后再自行决定是否清理旧下载文件。

不能把整个 v0.8 文件夹拖进去覆盖旧文件夹；尤其不要覆盖 `data`、复制新版基线替换自己的工作库，或删除 `.venv`。

## 保留内容

- `.venv` 依赖环境。此版本第三方要求不变，升级器不重装依赖；后续正常启动以 `uv sync --frozen --inexact` 保留额外包，控制台启动在同步后使用 `uv run --no-sync`。
- 所有 `data/versions/`、馆藏目录、收藏、浏览历史、日志、配置、缓存、操作次数、图片引用和已下载媒体。
- 根目录旧配置、`data/versions.json`、版本排序、版本管理日志、回收的工作版本、原基线数据库。
- 固定路径，以及因此依赖该路径的快捷方式和可选浏览器助手。

发行包不包含个人密钥或工作版本。升级器不读取配置密钥正文，也不把它们写入升级日志。

## 校验、备份和失败

先核对应用身份、安装版本、迁移链、允许覆盖的路径、旧文件及新文件哈希；再取得升级锁。数据库、个人配置、`.git` 和 `.venv` 不得进入普通覆盖清单。目录逃逸、符号链接／Windows 联接点和本机改过的程序文件会被拒绝，而非静默覆盖。

每次升级的程序备份、步骤记录及时间戳保存在 `data/updates/<事务>/`；已安装的程序版本记录在 `data/install_state.json`，安装历史在 `data/update_history.jsonl`，这些均在馆藏版本之外。普通失败或 Ctrl+C 会尝试回退全部已执行步骤。若文件权限、磁盘故障等连回退也阻止，错误会明确列出未恢复路径及备份位置，不宣称恢复成功。断电或强行结束进程不能保证自动回退；保留备份并完成恢复后再启动。

本轮依赖要求不变。如果未来迁移清单声明依赖变化，升级器先备份原环境，再按新依赖协调；失败时恢复备份。大环境会需要相应时间和磁盘空间。备份不是新建一个供用户手动搬迁的安装目录。

## 多版本升级

升级器能顺序执行一份包中提供的完整链，例如 `0.6 → 0.7 → 0.8 → 0.9`，所有步骤完成后只写入一次最终版本并重启一次；后面失败会回退整条链。**完整 v0.8 包包含真实的 0.6→0.7、0.7→0.8 两步；小补丁仅含 0.7→0.8**。升级器校验整条链后一次执行，全部成功后才启动最终 v0.8。0.9 尚未实现，未来必须携带真实迁移与载荷；不能用 v0.7→v0.8 小补丁直接更新 v0.6。

```bash
# 仅预览，不写入，也不启动服务
python update.py --target "D:/Apps/SpiceAtlas" --dry-run

# 完成后重新启动原位置的程序
python update.py --target "D:/Apps/SpiceAtlas" --restart
```

macOS／Linux 可运行 `bash Update_Atlas.sh /原来的/图鉴目录`。当前不自动从 GitHub 下载、不执行 git reset/pull，不自动安装浏览器扩展。

## 此前 v0.8 候选版 → 第二轮 v0.8

版本号仍为 0.8.0，构建为 `0.8-review2`。使用新补丁中的 `Update_Atlas.cmd` 指向原安装目录即可，不需要新建目录。首次访问每个馆藏时，名称与分类只修订未自定义字段，先生成 `catalogue_backups/names-20261031-v08-review2.sqlite3`；保留收藏、历史、设置、计数、别名、缓存及 `.venv`。旧安装的基线数据库、gzip 和校验文件保持原有配对。不要覆盖个人 data 目录。详见[第二轮验收](V08_REVIEW2.zh-CN.md)。

## 分屏修复版 v0.8 · 第三轮

构建为 0.8-review3，支持第二轮 v0.8 同版本原位更新。升级保留个人数据。更新完成后，**在扩展管理页对原助手点击“重新加载”，然后刷新图鉴**；助手应显示 0.8.1。继续使用原安装位置的 browser_helper，不要重复安装临时下载目录中的副本。详见[第三轮验收](V08_REVIEW3.zh-CN.md)。

## 第四轮分屏与目录修订
