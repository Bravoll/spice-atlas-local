# 项目决策与需求记录

本文件用中文维护可供开发者阅读的决策摘要，不保存账户登录、密钥或完整私人聊天。版本变化以根目录更新日志为准。

## 2026-10-27：范围与设计

- 从欧芹碎出发，逐步认识名称、部位、成分、种植地区、菜系、菜品、形态和包装。
- 先建设本地可检索目录与有出处的阅读器，再考虑视频生产；不一步完成全部自动化。
- 植物、调味原料、加工形态、包装实例分别建模。同科关系不直接说明风味相似或可以替代。
- 以自然史图鉴为视觉方向，材料配色和历史展签分别维护；不根据最近年份、最近地名直接断言起源。
- 采用可追溯来源，正文超链接和图片许可应保留。无法嵌入的来源提供明确跳转。

## 2026-10-28：目录、语言与本地版本

- 主搜索只查一次性建立并可更新的本地库；选择条目后再读在线正文和图像。
- 清洗不属于原料或植物的对象，保留排除／待定／合并档案。植物参考不代表食用确认。
- 手动简体、繁体、英文及自动英文／繁体使用国际来源顺序。只有自动识别简中时采用百度百科、国内 Bing 优先。
- 来源先测试、暂时隐藏失败服务，并每十分钟重测。通知在右上角，下一次内容操作时才全局刷新布局和完成操作。
- 设置、目录、缓存、词库、收藏、历史和日志归属各工作版本；版本登记和管理日志独立保存。
- GitHub 私有源码同步已完成；自动更新、完整作者和源码许可页面另行安排。

## 2026-10-29：0.5 验收范围

- 减少图片区纵向堆叠：左侧标题与形态，右侧来源与新窗口链接，中间留白。
- 原站视窗随容器变化适应；跨域内容不能由本机强制改写，提供整体缩放和原始尺寸两种模式。
- 新增可滑出的阅读快捷栏，字号、行距和字体独立于页面缩放；关闭时保存。
- 四档动画中，0 关闭，1 轻量，2 常规细节，3 植物色彩晕染；尊重减少动态效果，不承诺未实测帧率。

- 新增随机探索、三种启动策略和阅读操作返回／前进。返回不会撤销设置、收藏或数据库修改。
- 默认项目首页英文，中文首页单独提供；用户文档提供双语入口，开发和决策文档中文维护。
- 早期日志根据归档追补；v0.1 规划不得当成已完成功能。
