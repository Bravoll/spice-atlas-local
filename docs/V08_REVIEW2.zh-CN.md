## 章节点击

目录收拢与展开共用 32px 固定行高，文字省略不挤压相邻行。点击文字、短线或行内空白均按该行 ID 跳转，不再由自动可见面积计算立即改选下一章节。手动滚动正文后恢复自动章节跟踪。嵌套在标题中的 span 锚点定位到所属标题。

Chrome 合成正文检查中，三个目录行的 y 坐标在展开前后均保持 249.48、281.48、313.48；点击第二行选中 `fixture-classification`，正文标题定位到 y=185.20。此处合成正文只验证交互，不用作实际百科抓取或名称核对证据。

## 升级与个人数据

v0.7 或此前的 v0.8 候选版均可使用新补丁中的 `Update_Atlas.cmd`，选择原安装文件夹。先正常停止服务，不覆盖个人 `data/`，不删除原目录或 `.venv`。v0.6 使用完整包内的连续迁移步骤。

每个馆藏在首次访问时修订已知字段，先保存完整 SQLite 备份至该馆藏的 `catalogue_backups/names-20261031-v08-review2.sqlite3`。事务失败回滚，不进行部分修订；修改前后值及跳过的自定义字段有审计记录。自行修改过的名称、别名、身份及科属字段保留，不因发行升级整库覆盖。收藏、历史、设置、统计及媒体缓存继续保留。基线 gzip 与校验文件保持配对，旧安装不替换这组个人基线。

## 抽查建议

1. 阅读模式展开目录，连续点击相邻父／子章节，确认鼠标对应行和高亮一致；手动滚动后确认自动高亮恢复。
2. 搜索紫苏、赪桐、柚木、神香草，并按学名对照来源与别名。
3. 随机查 `names.csv` 中不同科属，核对“有出处”和“缺失”状态；缺失条目应显示学名，不出现拼音冒充中文。
4. 在旧安装中修改一个名称、收藏、字号并浏览一次，升级后确认这些记录保留。

完整后端、UI 和实际 ZIP 升级结果见 `data/verification_v08.json`；Windows 原生窗口／托盘仍需在目标 Windows 设备检查。本轮浏览器截图使用合成正文，名称来源来自独立的真实数据下载。
