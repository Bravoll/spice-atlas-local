# v0.8 第三轮验收：分屏助手连接与自动打开

程序发行号仍为 **0.8.0**，构建为 **0.8-review3**；分屏助手独立版本为 **0.8.1**。保留第二轮章节与名称修订，本轮未 commit 或 push。

## 已复现的缺口与修复

- 页面仅探测一次，旧桥接在 document_idle 注入，存在错过探测后持续未连接的路径。现在提前注册、主动宣布就绪，在页面回到前台或点击分屏时重新检测；过期探测不能覆盖新连接。
- 旧后台只使用可选 sender.tab.url，属性缺失会丢弃合法请求。现在使用浏览器提供的 MessageSender.url，限制顶层本机图鉴页面，并显式声明仅本机的 host_permissions。空回复不再导致页面读取 result.ok 时抛错。
- 显式调用 tabs.createSplit，匹配窗口、相邻位置、固定及标签组状态，并核对两侧实际 splitViewId。失败给出原因，复用助手创建的独立标签，不替换其他用户分屏。
- 已有缩略图但原站禁止内嵌时，旧判断跳过原站／分屏处理；现在两种展示可同时保留。
- 来源核验可保留两分钟内的真实操作；无操作或过期时要求点击分屏按钮。伪造事件不能授权，切换条目后过期来源不能补开分屏。
- 完整发行包的基线校验针对最终打包 SQLite 计算；源码 gzip 配对不变，旧安装继续保留自己的基线。

## 本机验收

1. 停止旧服务，运行新补丁的 Update_Atlas.cmd，选择原安装目录。
2. 在扩展管理页对原助手点击“重新加载”，必要时允许本机站点访问，然后刷新图鉴。首次安装才加载原目录中的 browser_helper。
3. 在同一浏览器选择 Google／Bing／百度图片，确认“助手 0.8.1”及接口可用；受限来源应在图鉴旁分屏。
4. 再换条目或来源，确认复用原站标签；处于不相关分屏中时应提示先退出。
5. 没有接口时应明确说明，调用失败时应显示原因并保留原站入口。应用内置窗口不共享独立 Chrome／Edge 的扩展。

名称核对、收藏、历史、设置、媒体、缓存及 .venv 继续按原位升级合同保护。
