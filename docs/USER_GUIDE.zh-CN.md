# 香料图鉴 · Spice Atlas

[English](../README.en.md) · 简体中文 · [版本记录](../CHANGELOG.zh-CN.md)

**本地目录 · 在线出处 · 双语阅读**

公开仓库提供应用源码；Python 服务在你的电脑上运行。仓库公开不代表已经部署了在线网站。具体变化见[版本更新记录](../CHANGELOG.zh-CN.md)。

在自己电脑上运行的植物与调味原料资料阅读器。目录和检索留在本地；点击条目后读取在线百科与图片，保留来源、正文链接和图片署名。页面沿用植物图谱的纸张、材料配色和展签排印。

## 启动与升级

需要 Python **3.11 或更新版本**。首次安装依赖及获取新资料需要联网。

**Windows：**完整解压到可写的新目录，双击 `run.cmd`。窗口名为 **香料图鉴 - Spice Atlas**，依赖安装和服务在后台运行，窗口显示阶段进度，确认 API 就绪后才打开网页。Windows 优先通过默认 Shell 打开浏览器；控制台入口等待匹配的本地服务最长 120 秒，回环检测不走代理。托盘悬停显示应用名，**单击显示／隐藏窗口，双击打开网页**；右键菜单可暂停／继续服务、打开日志或停止服务并退出。关闭窗口会收起，服务继续；托盘不可用时保留窗口。图形启动器需要 Python 的 **Tcl/Tk**；`run_console.cmd` 保留可见控制台入口。

**显示详细过程／隐藏详细过程**使用同一个按钮切换，日志右侧增加竖向滚动条及“跳到最新”。启动之后仍持续显示 HTTP 请求、来源读取、控制操作及网页控件标识；面板隐藏时日志文件照常记录，网页事件仅发送控件标识，HTTP 追踪不记录请求正文和认证头；导入进度等审计信息照常保留，敏感字段脱敏。暂停保留客户端与端口，拒绝新的内容 API 操作，并暂停诊断及目录任务；已发出的外部请求可能需要等有界超时结束。完全暂停前先向网页发送持久通知。继续时复用同一服务，并新增带“重新测试连接”的通知；自动诊断等待这次手动重测。启动窗口根据控件实际尺寸及文字换行调整最小尺寸，保留紧凑／详细两种大小，按钮改为与主题协调的两列布局。

百分比代表已完成的启动阶段，不是下载字节进度：30% 开始检查依赖，90% 等待本地网页就绪，确认后打开浏览器。日志在 `data/launcher/logs/`。从同一目录再次启动会打开已有实例；8765 端口被占用时可选附近空闲端口并打开实际地址。Windows 原生窗口与托盘仍需在 Windows 设备验收，进程生命周期自动测试另有记录。

**macOS / Linux：**在解压目录执行 `sh run.sh`。保留终端运行，Ctrl+C 停止服务。默认地址为 <http://127.0.0.1:8765>。

| 方式 | 命令 |
| --- | --- |
| uv | `uv sync --frozen --inexact`，然后 `uv run --no-sync python launch.py` |
| pip | 创建虚拟环境，安装 `requirements.txt`，再在该环境运行 `python launch.py` |
| 更换端口 | `python launch.py --port 8766` |

通过本地 HTTP 地址使用；直接打开 HTML 无法连接后台。Node.js 只用于可选开发检查和合成预览。

**已有安装：**使用 v0.7→v0.8 增量补丁（v0.6 使用完整 v0.8 包），或完整新包中的 `Update_Atlas.cmd`，先从托盘停止服务并退出，再选择原目录。升级器校验并备份程序文件，保留路径、`.venv`、所有馆藏工作版本、收藏、历史、设置与缓存，失败回退整条链，不用新版基线覆盖个人数据库。详见[原位升级指南](UPGRADING.zh-CN.md)。第一次安装才直接使用新目录中的 `run.cmd`。

Git 仓库中的基线数据库以 `data/catalogue.sqlite3.gz` 压缩保存，首次启动会核对 `catalogue_seed.json` 中的大小与 SHA-256，自动恢复成本机 SQLite 文件。已存在的数据库不会被解压覆盖。密钥、缓存与可编辑版本目录由 `.gitignore` 排除。

名称展签位于顶部，按界面语言排列并独立选择字体；临时选择进入浏览操作历史，默认值保存在每个工作版本的设置里。百科正文改为全宽，章节导航置于正文上方；Wiki 及语言选择在章节标题右上，来源备注紧随标题。

图片区显示实际检索词，可读的公开结果元数据重排为缩略图、标题与来源链接。遇到验证或禁止内嵌时，保留原站新标签入口；随包的[可选分屏助手](../browser_helper/README.md)在实际浏览器 API 可用时打开原生分屏，本轮不自动安装。不能靠浏览器版本号或网页脚本强行取得扩展权限。

**分屏助手升级：** 本轮助手为 0.8.2。更新后请在扩展管理页点击该助手的“重新加载”，再刷新图鉴；仅刷新网页不会更新扩展。受限来源会自动尝试分屏；分屏按钮可重新连接和重试。图片来源下方显示助手版本、连接及接口状态。请使用安装扩展的同一浏览器，应用内置窗口不共享其他浏览器的扩展。

## 沉浸阅读与字体

在探索界面选好条目，点击页首“阅读模式”。界面保留品牌首页、顶部本地搜索、主题与 Aa，收起目录、服务商及图片形态开关。先显示本地名称、学名、拼音与读音；维基完整正文准备好后一次呈现。Commons 图片按实际返回的原料形态分组，没有图片的分组直接省略；图片仍保留文件页、作者及许可。最多查询条目的前八种形态、同时两路，每组最多三张，整轮 40 秒后结束。

左侧细窄章节标记根据层级缩进，悬停、键盘聚焦或点击可展开名称。活动章优先选完整位于正文视口的章节，再比较可见高度；充分可见的子章节优先。微小滚动维持上一选择，避免闪烁。译文目前仅涵盖重点段落，所以切到译文／双语时收起不再对应全文的章节标记，保留范围提示。

“退出阅读”恢复进入前的来源、形态、图片窗口与位置。若阅读中更换了条目，回到当前条目的默认探索来源。返回／前进记录阅读开关、字体和条目；点击标题首页清理临时查询与排印，不清收藏、历史、设置或统计。阅读模式不预取其他探索来源。维基缺失或失败时显示可重试的结束状态。

名称标签写具体语言：英文界面左英文右中文，中文简繁界面左中文右英文。未来其他语言已预留左目标语言、右英文及 `localized_names` 字段，本版仍只开放三种 UI，不把缺失名称自动翻译成已确认事实。英文常用名／拉丁学名的内容选择与字体族独立。

探索界面名称下拉框可临时选字体；设置保存每个馆藏的中文（对应当前简繁）／英文默认字体。Aa 中另选正文字体，预览后关闭面板自动保存。目录含 31 项字体族，尽量显示“原名字体 · 界面别名”，没有已收录别名则保留原名。中文简繁别名分别显示，例如 `Times New Roman · 新罗马／新羅馬`；这类别名不代表字体的官方商标译名。

浏览器支持 Local Font Access 时，可在 Aa 点击“读取本机字体”，由浏览器请求授权；授权成功才补入族名，清单只在网页内存中存在，不随设置上传。没有此 API 或拒绝授权时，仍可用字体目录，或手动输入系统字体族名。列表中的字体不保证已安装或覆盖当前语言；系统会回退显示。此操作不安装或下载字体。

## 阅读体验

- 左栏固定为当前层级与条数、路径和子集、条目与常驻页码、底部统计几个区域；容量随窗口高度调整，条目不伸到栏外。子集路径固定在区域顶部，分页按钮在鼠标停留期间保持原位，移开后再平滑归位。目录导入与管理只放在设置中。
- 图片区左侧为章节标题与形态筛选，右侧为服务商与新窗口链接，保持两端对齐和中间留白。
- 正文增加可用宽度、调整换行。原站视窗默认按实际容器宽度显示，可选缩放预览；“展开视窗”使用几乎整个浏览器视口，收回时保留同一 iframe 的输入和滚动。尺寸变化后自动重算；跨域页面内部排版、最小宽度与嵌入权限仍由原站控制。
- 右侧 **Aa 阅读**标签滑出快捷栏：字号 14–28 px、行距、书页衬线／无衬线／楷体；文章文字单独改变，导航不随之缩放。点击外侧、完成或 Escape 后保存到当前工作版本；保存失败则保留面板。
- 四档动画：0 无动画，1 轻量，2 舒适，3 加入缩略图方向的弹窗、局部光晕、列表错峰、英文词／中文单字的轻翻入、来源文字显现、支持时的原生下拉开关过渡和新卡片入场。主题即时变色，不再等待整页截图；最多同时 64 个短文字单元，表格与长文正常排版。打开和关闭共用动画生命周期，退出完成后归还焦点。系统“减少动态效果”优先。使用 CSS 和浏览器原生动画，不设置固定帧率定时器；实际刷新率由设备和浏览器决定，本次未在 120 Hz 屏幕上测量。
- 英语常用名称优先展示公开词典返回的 IPA，保留来源。播放优先选择 UK / GB 音频，否则通过浏览器 Web Speech 优先选择 en-GB 语音。本机没有英式语音包时会说明，不能保证每台设备都具备同一口音。没有音标时不生成；不合成拉丁学名朗读。
- 中文拼音由本地 pypinyin 自动生成并标明“自动拼音”；多音字和专名需核对。词典音频不随包分发，页面保留相应来源和许可。
- 正文左上角固定的悬浮“返回／前进”记录最多 60 个阅读操作，包含条目、形态、来源、图片筛选、目录、阅读模式和滚动位置。回退后进行新操作会清空前进分支；不会撤销设置、收藏和数据库修改。点击左上标题回到罗勒默认首页，只清临时路径、过滤与来源选择，保留历史、收藏、设置和累计统计。加载完成不再覆盖等待期间的滚动。记录在当前标签页中按工作版本分开保存。
- “随机探索”只从本地已准入条目抽取，排除当前项，默认范围为香料候选。设置可改为植物参考或全部；随机选中仍不代表可食用。
- 设置 → 阅读与语言：启动时可继续上次阅读、固定罗勒或随机展示。全新工作版本默认罗勒；明确指定的条目链接和服务变化触发的操作恢复优先。
- 第一次完整连接测试之前，所有来源默认可选；完成后才临时隐藏失败来源并通知。

项目首页按完整英文、完整中文的顺序排列，另有独立的英文和中文文件。更新日志及第三方声明提供两种语言，开发和决策记录用中文维护。英文界面的学名备注使用英文显示，例如 Thymus (genus)；原始名称与身份字段保留。

## 先从这几个操作开始

1. 页首选择“自动 / 简体中文 / 繁體中文 / English”。自动跟随浏览器首选语言，通常与系统语言相关。
2. 左侧输入中文、英文、学名或已收录别名。这一步只查询本地数据库，不发送在线搜索。
3. 点击条目，右侧按语言和当前可用服务列出来源，同时自动查询 Commons 图像。
4. 点击“鲜叶 / 干叶碎”等材料形态；图片区还可独立选择粉末、整粒、树皮、根、切片、玻璃罐、袋装等检索形态。图片筛选不改变百科内容。
5. 设置 → 翻译服务：填写本地 LM Studio 接口并测试，或配置自己的 Google Cloud / Azure 翻译密钥。
6. 点 ☆ 收藏；左侧可切换收藏、历史。在设置中管理排序、版本和操作日志。

桌面页面固定在视口内，目录内部区域与正文分别控制滚动；移动窄屏恢复普通页面滚动，目录占用高度有限。名称展签的字体是现代排印意象，不能据此认定香料的历史起源。

## 快捷键与重复操作

| 按键 | 功能 |
| --- | --- |
| **R** · Repeat | 按当前状态重复最近一次适用动作，例如继续翻到下一页 |
| **[ / ]** | 子集列表上一页／下一页 |

悬浮栏的 R 会提示当前可重复的动作；到达边界时停止。命令使用当前查询、范围和页码，加载中的连续请求合并处理。输入框、下拉框、可编辑文本和输入法组合期间不触发单键命令。弹窗中的命令仅作用于该弹窗；原站 iframe 内的键盘输入属于原站。Esc 不是撤销数据库修改。

## 语言与来源顺序

界面语言、优先正文语言、翻译目标分别设置。

| 界面模式 | 优先语言的来源顺序 |
| --- | --- |
| 仅“自动”，且检测为简体中文（如 zh-CN、zh-SG、zh-Hans） | 百度百科 → 国内 Bing → 其他资源（含可用维基） |
| 自动英文、自动繁体、手动简体、手动繁体、手动英文 | 对应语言 Wikipedia → 国际 Bing → Google → 其他资源 |

另一语言的来源列在后面。中英文 Bing / Google 各有独立的语言检索参数。手动简体**不会**沿用国内优先策略。

维基正文支持实时读取、重点章节、完整正文、章节导航、外部超链接和引用回原站。维基有独立的按钮和英文／简体／繁体选单，先读英文页跨语言链接，缺中文再独立搜索并校验学名或身份；没有中文对应页时回退英文。已有中文映射不等待后台语言发现。切换界面语言清掉过时的 Wiki 显式选择，保存排队并拒绝迟到回复。连接失败不会被当成“条目不存在”。Bing／Google 在阅读器显示明确标注的公开检索结果；已审阅站点可继续读取正文，并可返回结果页。GBIF 使用 v2 分类 JSON 并兼容 v1；NParks、ICAR 等读取有界 HTML，Wikidata 展示名称资料。无法读取正文、需要验证或只有动态外壳的网站提供明确状态和原站入口；不会把搜索链接冒充 API 图片或百科全文。

## 目录快捷键与通知

子集列表用 **[ / ]** 上／下翻页，条目用 **, / .** 上／下翻页；N / P 保留为条目翻页别名。四个主快捷键可在“设置 → 缓存与快捷键”自定义，输入框、下拉菜单及输入法组合期间不会抢按键。

铃铛周围增加半个半径的感应圈，鼠标进入即展开；离开整个通知面板四边再加半径一半的缓冲区后才反向收起。靠近后立即点击不会误删通知；有意继续点击原位可关闭首条。暂停前、暂停后和继续服务也使用此通知队列，继续后可在卡片上手动重新测试连接。

诊断仍在开始后的 **2000 ms** 统一发布一次。未在截止前完成的探测是“尚未确认”，保留之前的可用性，初始保持开启；只有明确失败的证据才临时禁用。维基／Commons 的浏览器和后台路径分别判断，任一路径成功即保留。正文沿用 v0.6 的实际 Wiki 读取回退；不会因短探测超时而变成搜索页。

## 闲置预取与本地缓存

仅统计和缓存互联网资料。本地搜索、目录翻页不参与预测。闲置时顺序预热完整目录前 30 项及收藏条目，长期保留；“设置 → 缓存与快捷键”显示历史／本次启动／最近 30 次的操作分布、当前系数、资源指纹、访问次数和缓存层级。

启动初期以历史为主，默认在 30 次在线操作内逐渐转为 **历史 20%＋本次 30%＋最近 30 次 50%**；三个系数、过渡阈值和留存次数均可调整。只预测当前状态下一步可到达的内容，不递归扩展。预测结果仅驻留内存：每版本 32 MiB、全局 64 MiB、最长 30 分钟；用户继续操作会取消旧预取，不替换当前画面。

同一资源包默认累计 **6 次独立访问**后长期保留；读取先查缓存。长期资料保留原获取时间、来源和许可，主动“刷新”跳过旧内容并取得新版本；长期缓存不自动过期。复制工作版本会保留累计统计、资源记录和长期缓存，不复制预测内存；新一次启动单独计数。不主动预取收费云翻译。

详细规则见[缓存设计](CACHE_DESIGN.zh-CN.md)和[本轮修订记录](V07_REVIEW_FIXES.zh-CN.md)。

搜索响应只有动态外壳时，若原站响应允许嵌入，阅读区可尝试原站搜索视窗。重定向仅在已批准的 HTTPS 搜索引擎主机中进行。这仍是回退尝试，不保证可用：本轮实际 Bing 响应没有可提取的文字结果，Google 文字检索超时。

非 Wiki 来源独立加载和刷新，不等待 Wiki 语言发现。部分连接失败保留已验证链接并标记未确认；切换条目或返回原文后，过期详情和翻译任务不覆盖新的选择。失败条件与验证边界见[第四次审查说明](V07_REVIEW4.zh-CN.md)。

## 其他知识来源

点击 **其他来源**会展开横向阅读卡片。后台完整收到一篇资料后，才按完成顺序放入高窄卡片，保留原标题、章节、正文、原文超链接、来源地址和适用条款；正文可独立纵向滚动。新卡片从右侧出现，仅当你已停在最右端时自动跟随。停止请求会保留完整卡片，刷新或切换条目会取消上一轮。

来源注册表现为 **21 组提供方**，比原调查增加百度百科和 McCormick 公开页面适配。原来的 19 组从 18,379 条本地目录中按固定随机种子分层抽取 **184 条**，整理出 **257 个候选链接**，包括邱园、世界植物志、IPNI、NParks、大学推广资料、区域植物志，以及 Wikispecies、Wikibooks 和 GBIF API。候选链接不保证可读取。其余名称可通过公共 API、名称候选路径和可选的 Google／国际 Bing／国内 Bing 第一页检索补充查找，正文只从已审阅的站点读取；验证页、名称不符、空内容和错误会单独记录。

设置 → 网络与诊断中可调整单源超时（默认 **25 秒**）、整轮上限（**35 秒**）、卡片上限（**6 张**）和是否补充检索。正文保留可读 HTML 结构并清理脚本、控件和远程文章图片，重写章节 ID 与原文链接。卡片目前保留原语言，下方重点段落翻译控制针对维基阅读器。

原调查直接访问三家指定搜索引擎未取得可提取结果，补充检索研究另行标注；新适配器核验单独保存，不覆盖该历史结果。真实读取抽查中，欧芹、牛至和一个植物参考条目共返回 7 张卡片；通用 HTML 网站另有 DNS 限制，未将候选网站全部标记为已验证可用。方法、结果和限制见[来源调查](SOURCE_RESEARCH_v0.7.zh-CN.md)及[本轮修复](V07_REVIEW3.zh-CN.md)。

## 翻译设置

默认提供本地兼容接口配置：`http://127.0.0.1:1234/v1`。先在自己的 LM Studio 启动服务器；“保存并测试 / 读取模型”会启用本地连接并调用 `/models`，实际翻译调用 `/chat/completions`。应选择支持聊天和结构化 JSON 输出的文本模型。未启用的本地服务不参加启动诊断。

- 开启自动翻译后，来源语言不同于目标时，默认通过选定服务翻译最多 **8 个合适的重点段落**。
- 阅读器可切换原文、机器译文、双语；这版尚未做全文批量翻译。
- 多选“排除语言”可跳过自动翻译；“中文（全部）”同时覆盖简体与繁体。
- Google 使用官方 Cloud Translation Basic v2；Azure 使用官方 AI Translator v3。需要自己的账号、API 凭据与配额；两者都不是抓取搜索网页上的翻译按钮。
- Google 翻译密钥与 Google 图片搜索密钥是两个独立配置。
- 翻译保留来源链接占位符并校验数字，失败时保留原文。任何机器译文仍需核实。
- 配置好的云端翻译服务会用一小段 Parsley 文字检查连接，可能计入用量。

密钥由本机后台保存在所属版本的 `config.local.json`；设置读取接口只返回是否已配置。输入框留空保留密钥，勾选“删除”才清空。复制版本也会复制其设置与密钥。请勿分享自己的版本目录。环境变量可覆盖配置，界面会保留覆盖字段信息；清空配置不会删除操作系统环境变量。

本项目后台和 LM Studio 应运行在你的电脑上。其他机器、容器或云环境中的 localhost 不指向你的电脑。

## 启动检测与右上角通知

来源在首次检测前默认开启。第一次打开网页加入一个固定 **2000 毫秒**的诊断轮次，收集后台和浏览器结果，到点一次发布、取消未完成请求；未完成项记为尚未确认并保留上次可用性，迟到结果不再恢复按钮。后续轮次检测时保留上一轮发布状态。每轮结束 **600 秒**后再检查全部服务，包括失败服务。默认测试欧芹 / Parsley；无欧芹映射的专用站使用记录的代表页面，并在诊断中说明。

- 全部可用时不弹通知。
- 无法连接的服务只在当前运行状态中临时禁用，其正文或图库按钮暂时隐藏。
- 状态改变时显示右上角主题色铃铛与数字浮球。鼠标悬停展开独立卡片，触屏与键盘可点击展开；浮球原位变成首条通知的关闭按钮，关闭后下一条上移，通知需手动关闭。
- 检测不会打断当前阅读。下一次内容操作时保存条目、形态、来源、搜索、目录位置、阅读模式及两栏滚动位置，然后全局刷新并完成刚才的操作。
- 后台与浏览器直连分别判断；维基和 Commons 的有效浏览器测试可以证明浏览器路径可用。
- 网页可访问但禁止 iframe，不等于网络失败。Bing 仅在实际响应允许时自动尝试搜索视窗；Google、百度常有嵌入限制，保留原站链接。
- 详细诊断与手动重测放在设置 → 网络与诊断，正文附近不再放功能性诊断按钮。

403 / 429 / 5xx 是本次请求的状态，不证明来源永久不可用，也不代表其 API 一定不公开。配置代理时填写真实的本机代理地址；不绕过网站的验证或嵌入策略。

## 目录导入：两个数字是什么意思

“向下分类层数 2”：起始分类是第 0 层，2 表示读取它的子分类和孙分类。它是维基分类链接深度，**不是**植物的科／属／种等级。

“单次分类数量上限 200”：最多处理 200 个分类目录，**不是** 200 个材料条目。达到上限会保存队列与分页游标并暂停；提高上限后点继续即可续传。两项旁的 i 按钮、关于页均有说明。

同步只导入目录、身份、名称、别名和来源映射。正文和图片按需读取。GBIF 默认提供唇形科、伞形科、胡椒科的固定 Backbone 数据集范围，不假定这些植物均为调味材料。

在线查找并导入放在设置里，需要主动点击；主搜索框始终是本地查询。导入途中可暂停、续传，日志记录时间、处理内容和进度；重启后不会自动下载全部正文。

命令行可用 `uv run python scripts/catalogue_sync.py wiki --depth 2 --max-categories 200`，或 `... gbif`。不要同时启动两个应用实例，或同时通过 CLI 和网页导入同一馆藏；版本管理器目前采用单进程的写入协调。

## 版本、收藏、历史与日志

“版本”是一个可继续编辑的独立工作空间：

- 可命名、复制任一版本、从内置基线及默认设置新建、切换、重命名、删除和恢复。
- 目录、配置、缓存、图片关键词库、收藏、浏览历史、运行日志与阅读状态各自保存。
- 版本管理登记文件及管理日志在版本之外，不随某个版本复制。
- 版本按名称、创建时间、修改时间或自定义顺序排列。拖动或使用上下箭头会记住自定义顺序；收藏和历史也支持。
- 复制／切换前暂停相关导入。复制保留可续传游标；从默认设置创建不会复制个人密钥、收藏或历史。
- 异步请求绑定发起时的版本；旧标签页不能把修改写入新活动版本。
- 删除进入可恢复区，本版不提供不可恢复清空按钮。

当前版本会继续变化，并非只读历史备份。需要冻结某个状态时先复制并命名，之后在另一个副本继续。磁盘备份仍建议关闭应用后复制整个 `data/`。

磁盘布局：

```text
data/catalogue.sqlite3             已清洗的内置基线
 data/versions.json                全局版本登记、活动版本和排序
 data/version_manager.jsonl        全局版本操作日志
 data/versions/<id>/
   catalogue.sqlite3               该版本的目录、分类、任务、审核档案
   config.local.json               该版本的设置与密钥
   activity.sqlite3                收藏、历史、日志、通知
   cache.sqlite3                   正文、翻译与图片元数据缓存
   image_keywords.sqlite3          图片形态词库与采样记录
   view_state.json                 阅读与列表位置
   media/                          仅在中转需要时缓存的图片
 data/version_trash/<id>/          可恢复的已删除版本
```

## 图片词库、署名与限制

图片词库包含 12 类形态，依据 30 个不同原料的 39 次真实 Commons bitmap 查询记录，返回文件名共 326 条；4 次空结果也原样保留。查询时间、参数与词频见 `data/image_lexicon_seed.json` 和研究说明。它是代表性抽样，既不是随机样本，也不是植物鉴定或食用证据。

进入条目和切换形态时，浏览器自动调用官方 Commons CORS API；失败后尝试后台路径。已有精选文件引用先读取实时文件元数据与许可，再回退关键词查询；取得首批有效候选即可呈现，不再等待所有关键词。默认直接显示远程缩略图，图片地址失效时自动尝试后台中转一次。没有独立的图库照片快照；README 另附所有者提供且保留许可的界面截图。当前筛选会排除常见成菜、显微照片等不合适标题，结果仍是候选图；空结果不会拿鲜叶冒充干叶碎。

三家原站视窗现在检测实际响应，不再直接写死拒绝。Google 图片的本轮实际响应为 SAMEORIGIN，百度跳到安全验证，Bing 允许尝试内嵌；不把这些限制宣称为已强制修复。公开结果元数据可取得时可显示本地图集，已有资格的 Google 客户可使用已配置 API；其余保留原站入口。

API、直链、iframe 都不等于获得版权豁免。每张图片显示作者、文件页、许可和原图入口。实际用于视频时，应逐图核对并保存署名、许可及修改记录。百度 / Bing / Google 搜索本身不提供图片复用授权。第三方内容许可详见 `CONTENT_LICENSES.zh-CN.md`。
